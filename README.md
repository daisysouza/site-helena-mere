# Helena Mere — Plataforma Imobiliária

Plataforma desenvolvida para apresentar imóveis à venda, fortalecer a presença digital da marca e facilitar o contato com clientes pelo WhatsApp.

🌐 **Site:** https://www.imoveishelenamere.com.br/

## Funcionalidades

- Catálogo de imóveis com filtros de busca.
- Páginas individuais com fotos e informações dos imóveis.
- Integração com WhatsApp para facilitar o contato.
- Favoritos e compartilhamento de imóveis.
- Páginas institucionais e conteúdo otimizado para SEO.
- Layout responsivo para celulares, tablets e computadores.

## Tecnologias

- Next.js 16 e React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui e Embla Carousel

## Estrutura

- `app/` — páginas e rotas da aplicação.
- `components/` — componentes da interface.
- `lib/` — utilitários e configurações.

## Publicação

O projeto está hospedado na Vercel, com deploy integrado ao GitHub para facilitar a publicação de atualizações.
